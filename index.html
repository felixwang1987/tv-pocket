把链接放进影视仓

  1. 首页分为四类：点播合集、抽检出画面的直播、需影视仓验证的点播配置、需影视仓验证的直播列表。「普通点播」也可合入配置可读的网盘站点。
  2. 日常可复制前两个合集：「复制点播合集」放入线路合集入口，「复制直播合集」放入直播配置。点播合集提供「普通点播」与「成人点播」。「普通点播」把标准接口和所选网盘站点放在同一配置；搜索范围设为全站／全部来源，可一起搜索。网盘需在「配置中心」用自己的百度网盘、阿里云盘、夸克或 UC 账号登录。
  3. 待验证来源可从后两个分类进入目录，单条复制到影视仓测试；加密配置即使可读取，也不能据此确认能播放或判断内部内容类型。
  4. 多仓用「多仓 / 仓库」入口；单配置用「配置地址」；直播列表用「直播配置」。不同版本的入口名称可能不同。
  5. 粘贴、保存，再实际测试播放。常用的来源可以点星收藏。
检查到哪一步？

直播列表每轮最多抽取 6 个频道，尝试下载视频分段并解码出 1 帧画面，每轮轮换样本。“已实测直播”只收录近 36 小时成功的抽检频道，去掉重复地址。

普通与成人点播会展开多仓与线路合集，从单配置里提取不依赖插件的标准 JSON 点播接口，检查节目列表、详情和视频画面。每个接口最多抽检 2 部节目；至少一部出画面才纳入，36 小时后过期。网盘合入只采用同一来源、同一插件的网盘与登录站点，保留所需配置上下文和相对地址；不把不同来源的插件混在一起。网页显示实际合入的网盘站点数量；备用原配置的可读数量不代表全部已合入。后台不登录账号或执行插件，未验证网盘播放。「普通点播」将普通标准接口与网盘放在同一配置，「成人点播」单独聚合成人接口，不再单独列出每个站点的配置入口。标准接口的搜索另行验证；网盘搜索支持按配置声明显示，结果多少取决于各站收录、账号权限和影视仓选择的搜索范围。
目录中原始单配置的“配置可读”仍只表示结构可识别。插件解析、网盘登录和会员权限需在影视仓实播；可读的网盘站点不会被标为实播通过。

GitHub Actions 的公网环境与你的手机、电视可能不同。超时或访问受限不等于永久失效；出画面也不保证持续流畅。可展开卡片查看每条样本的结果。

成人入口密码

直播合集使用 TXT 格式，影视仓 6.2.5 进入「成人直播」分组时可弹出密码框；旧 M3U 地址不支持这个密码流程，需重新复制直播合集并替换。当前「成人点播」仅独立分类，未加电视端密码，此版本不支持点播入口密码。网页保留原总访问码，不另设成人门禁；客户端分组密码也不能阻止别人直接读取公开清单。

链接怎样更新？

上传完整发布包并启用 GitHub Actions 后，每天自动寻找和检查来源。页面的「读取最新」读取已发布的检查结果，不会启动后台采集。

只上传这个 HTML，也能使用内嵌快照；想保持更新，需要一起上传配套脚本和工作流。具体步骤见发布包里的说明。

自己添加新来源

点首页「添加来源」，填公开直链或收集网页，再到 GitHub 用仓库所有者账号确认提交。收到提交后会自动检查，但可读不等于实播通过。GitHub Issue 公开可见，请勿提交账号、网盘 token 或私密链接；动态网页可能需要单独适配。

收藏与导出

收藏只在本机浏览器保存，清除浏览器数据会丢失。「导出当前列表」下载 JSON 清单，方便留存来源；它不是影视仓的通用导入配置。

长时间没有更新

超过 36 小时会提示数据可能过期。到 GitHub 仓库的 Actions 查看运行结果，也可以手动运行。公共仓库长时间没有活动时，定时任务可能停用。
