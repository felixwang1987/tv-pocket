# 影视口袋

用户已确认：自用，搜索、筛选、复制到影视仓；参照发票口袋，自己把 HTML 上传 GitHub。

## 交付
一个无前端依赖、可直接打开的 index.html，内嵌真实检查数据。另附 Python 标准库采集脚本、来源配置、测试、GitHub Actions 工作流与中文发布说明。用户自行发布，不创建远程仓库。

## 页面
沿用发票口袋的 #EEF0F7 底色、#4C5BD4 主色、#1E2140 文字、16px 圆角，手机优先。名称为影视口袋。主要流程：搜索名称/来源/地址 → 类型或状态筛选 → 复制地址。可在本机收藏。显示来源、条目数、最后检查时间和结果；不把下载成功说成可以播放。提供使用说明、重新读取已发布数据、下载当前筛选列表。

## 数据与采集
每 6 小时通过 GitHub 仓库搜索发现相关仓库，扫描候选配置文件和 README 链接，结合明确的起始来源。限制每次仓库、候选数、文件大小与超时。识别 storeHouse、urls、sites、M3U、直播 TXT；允许 JSON 注释和尾逗号。只读取远程文本，不执行 JAR、JS 或源站脚本。

只接受公共 HTTP(S) URL；禁止凭据 URL、本地/私有地址；重定向重新检查。认证头仅用于 api.github.com。配置嵌入 HTML 必须防止关闭 script 的注入。前端用 textContent 显示外部名称。

已有记录请求失败仍保留最后成功信息，同时标记本次失败；每次最多保留 500 条。发现服务失败和链接检查失败分别显示。超过 18 小时提示过期。收藏留在设备，非登录或跨设备同步。

## 部署
单 HTML 可展示随文件附带的快照。完整自动更新需要 .github/workflows/update.yml、scripts、sources.config.json、index.html、data。Actions 先测试、采集与内嵌数据，然后提交生成文件，单次流程部署 Pages。用户在 Pages 中选择 GitHub Actions。不得在浏览器嵌入令牌。

## 验证
解析与去重、错误保留、HTML 安全嵌入、私有地址拒绝测试；真实采集；桌面及手机预览，搜索、筛选、收藏、复制、导出、空状态、离线快照。实际 GitHub 工作流只有用户上传启用后可验证；频道可播放不在本次已验证范围。
