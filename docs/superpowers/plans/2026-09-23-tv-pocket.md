# 影视口袋 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 交付用户自行上传 GitHub 的影视仓链接目录与自动采集配置。
**Architecture:** 静态 HTML 包含可离线使用的数据快照；Python 标准库采集公开文本并生成 data/sources.json，再同步嵌入 HTML；Actions 定时发布。
**Tech Stack:** HTML / CSS / JavaScript / Python 3.9+ / GitHub Actions。
**Spec:** ../specs/2026-09-23-tv-pocket-design.md

## Global Constraints
- 用户自行发布，不创建远程仓库。
- 不执行远程代码，不将 GitHub 令牌放进前端。
- HTTP 200 不等于频道可播放。
- 前端零依赖；单 HTML 可用；每 6 小时更新。

## Review Focus
- 合法 JSON 字符串中的 //、逗号不得被注释清理破坏。
- 上游失败不得清空旧数据或冒充本次成功。
- 相同地址不同来源应合并来源。
- HTML 内嵌数据不得通过 </script> 注入。
- 子路径发布、file://、剪贴板不可用、收藏存储被禁用仍可浏览。
