影视口袋，放到 GitHub 上。

像发票口袋一样，先打开看看，再发布成自己的网址。

打开影视口袋 →

推荐：开启自动更新

  1. 在 GitHub 新建 Public 仓库，例如 tv-pocket。
  2. 解压发布包，把文件夹里面的内容上传到仓库根目录。根目录应直接看到 index.html、scripts、data、tests 和 sources.config.json。
  3. 检查 .github/workflows/update.yml 也已经上传。Mac 按 ⌘ + Shift + . 可以显示隐藏的 .github 文件夹。或者在 GitHub 用 Add file → Create new file 创建同名路径，复制本包同名文件的内容。
  4. 进入 Settings → Pages，把 Source 设置成 GitHub Actions。
  5. 进入 Actions → 更新影视口袋 → Run workflow，再点一次 Run workflow。等待采集和部署都变绿。
  6. 回到 Settings → Pages 打开生成的网站地址。以后大约每 6 小时更新一次。

不要直接上传 ZIP 当网页；不要漏掉隐藏的 .github 文件夹。HTML 单独能用，但自动更新需要配套文件。

无需填写 GitHub 令牌。工作流使用 GitHub 自动提供的凭据。网页地址是公开的，收藏只在本机浏览器保存。

只上传一个 HTML，也可以

上传 index.html 到仓库根目录，在 Settings → Pages 选择 Deploy from a branch → main → / (root) → Save。

这样有搜索、复制和收藏功能，但使用的是随文件附带的链接快照。想后台自动发现新链接，再按上面的步骤补齐配套文件。

使用时记住这三件事

  1. “格式检查通过”不代表每个频道都能播放，复制到影视仓后实际测试。
  2. “读取最新”只读取已发布的数据。想立即采集，在 GitHub Actions 手动运行。
  3. 收藏保存在当前浏览器，不会自动同步到其他手机或电脑。
